# ForVoyez

ForVoyez app: landing, dashboard and public API, served at forvoyez.com. Sister repos: For-Hives/ForVoyez-Doc (API docs), For-Hives/ForVoyez-Wordpress-plugin (WordPress client of the API).

## Agent skills

### Issue tracker

GitHub Issues, centralised on For-Hives/ForVoyez for all three ForVoyez repos. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), on For-Hives/ForVoyez. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
